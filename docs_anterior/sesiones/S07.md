# S7 - Ingesta de eventos IoT/sensores en tiempo real

## 1. Introducción
**Propósito de aprendizaje:** Llevar telemetría de sensores a Kafka.

## 2. Explica
Un puente (*bridge*) traduce el protocolo del sensor (MQTT) a eventos Kafka. El consumidor valida forma y rango de cada mensaje.

## 3. Aplica en EcoData Aire
Se construyó el flujo ESP32 → MQTT → Kafka (`atmos-eventos`). Para Aire, el mismo patrón se aplica con eventos `aire.lectura` en el topic `atmos-aire`, publicados desde Open-Meteo.
