# S6 - Ingesta de eventos empresariales en tiempo real

## 1. Introducción
**Propósito de aprendizaje:** Levantar Kafka y publicar eventos con un contrato y una clave de partición.

## 2. Explica
Kafka organiza los mensajes en **topics** y **particiones**; la clave determina la partición y conserva el orden por clave.

## 3. Aplica en EcoData Aire
Se levanta Kafka con Docker Compose y se crean los topics del proyecto (entre ellos `atmos-negocio`, donde se publican las alertas `aire.episodio`).
