# S10 - Series de tiempo e inferencia en streaming

## 1. Introducción
**Propósito de aprendizaje:** Aplicar un modelo de series de tiempo a cada evento que llega.

## 2. Explica
Las features de rezago (lags, diferencias, medias móviles) deben calcularse **igual** en entrenamiento y servicio.

## 3. Aplica en EcoData Aire
8 features (`l0, d1, d3, d24, m24, pm10d, hs, hc`) definidas en una sola función (`aire_comun.features`); el objetivo es `delta = PM2.5(t+1) − PM2.5(t)`.
