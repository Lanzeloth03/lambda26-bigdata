# S2 - Fundamentos PySpark: transformaciones, funciones, agrupaciones y evaluación perezosa

## 1. Introducción
**Propósito de aprendizaje:** Cargar el JSON horario de Open-Meteo y transformarlo con DataFrames.

## 2. Explica
Las transformaciones de Spark son **perezosas**: no se ejecutan hasta una acción (`count`, `write`). Se practican `select`, `withColumn`, funciones de fecha y `groupBy`/`agg`.

## 3. Aplica en EcoData Aire
Se lee `aq_juliaca_2023.json` (campos `time`, `pm2_5`, `pm10`), se explota el arreglo horario y se calculan agregados por mes y por día.
